## Agent A: single-trial adaptation and frequency information

Research date: 28 October 2026, Asia/Kolkata. Research only; no models, experiments, submissions, or cloud resources were run.

**Judgment.** BTTA-DG offers portable architectural and prediction-summary ideas, but its released reproduction does not establish an eligible chronological adaptation gain. Separate the published results from demonstrable defects in the public implementation: those defects do not prove that every published experiment used the defective paths. No PROTEUS improvement is demonstrated.

### Verified paper and reported evidence

Huan Luo, Na Lu, Xiaopeng Wang, and Xu Niu. **“Bayesian Test-Time Adaptation via Dirichlet feature projection and GMM-Driven Inference for Motor Imagery EEG Decoding.”** Published conference paper, **ICLR 2026**, verified through the [official proceedings entry](https://proceedings.iclr.cc/paper_files/paper/2026/hash/36eeec256f89eba9ed60cbca73ea92ed-Abstract-Conference.html) and [full paper including appendices](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf). The [author repository](https://github.com/luo-huan-123/BTTA-DG) identifies itself as the official implementation.

**Authors’ demonstrations:** binary scalp-EEG imagery, primarily first-session LOSO; BNCI2014001 also session 1→2 within participant. Dataset specifications are:

|---|---:|---|---|
| BNCI2014001 | 9 | 22; 250; 4 s | Left/right hand |
| BNCI2014002 | 14 | 15; 512; 5 s | Right hand/feet |
| BNCI2015001 | 12 | 13; 512; 5 s | Right hand/feet |
| SHU MI | 25 available; last 10 evaluated | 32; 512; 4 s | Left/right hand |

The method combines source-supervised SincAdaptNet, per-trial Dirichlet prediction summaries, and historical classwise GMM calibration. Ten-run mean accuracies: BNCI2014001/002/5001 LOSO **78.70/80.29/77.92%**; BNCI2014001 cross-session **86.50%**. EA-equipped source comparators: **77.03/78.05/75.48/82.33%**, respectively. Appendix E claims source-held-out hyperparameter selection, batch one, memory 1000, eight mixture components; Table 7 reports **15.7 ms/trial** on the stated TITAN V/Xeon setup. SHU’s improvement lacks statistical significance. These are reported accuracies, not competition cell-balanced accuracy. [Paper, Tables 2–8; Appendices E–I](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf).

### What the representation actually preserves

**Our mathematical interpretation:** the Dirichlet estimator uses time-averaged log probabilities. Permuting the columns of an already-computed prediction trajectory leaves its estimate unchanged. Thus it can retain class preference and within-window predictive dispersion, while discarding temporal order, transition timing, and distinctions between trajectories with identical sufficient statistics. It cannot preserve task information already removed by the encoder. This is a narrower claim than preserving arbitrary temporal dynamics. Adjacent filtered EEG samples also need not behave like independent draws; fitted concentration is therefore a descriptive feature, not automatically calibrated biological uncertainty. This reasoning follows [Equations 2–4](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf).

**Our interpretation:** classwise density correction can tolerate a change in where otherwise useful predictive patterns fall. It cannot identify a reversed class mapping without an anchor. Confidence-based admission remains pseudo-label-dependent despite frozen network weights. Multiplying a density and a network prediction derived from the same EEG is a calibration heuristic; their dependence prevents treating the product as independent new evidence. It does not independently estimate a new target class prior. Wrong confident predictions can contaminate memory without changing a single weight.

### Minimal project hypothesis and falsifier

**Untested proposal:** first compare a source-trained Sinc front end against the existing EEGNet using the same public training corpus, split, checkpoint-selection policy, and parameter budget. Separately compare frozen temporal-probability means with clipped mean-log/concentration summaries using a small source-trained classifier. This isolates spectral bias from adaptation and avoids cold-start memory ambiguity. Falsify the proposal if source-only summaries fail to improve validation cell-balanced accuracy consistently across the existing seeds, or if gain disappears under the official participant-session replay.

Only then consider a causal memory calibrator. Algorithm 1 takes memory banks as input without resolving cold start. An eligible target-memory implementation must reset each session, define insufficient-class fallback, and measure startup versus later-window performance and latency. For an initially empty target-only memory, our proposed control predicts before storing the current pseudo-label; that ordering is a design choice, not a competition rule. The [current official FAQ](https://raw.githubusercontent.com/neural-interfaces26/2026-competition/main/codabench/pages/scientific_faq_bci.md) also permits label-free adaptation on the current window. Warm-start target labels, session identifiers, future windows, and cross-session state are unavailable. Balanced target class proportions must not be assumed; a uniform prior could be tested as an explicit modeling choice. The short streams and three heterogeneous commands make missing-class memory and confident mistakes concrete falsifiers. Published hardware timing cannot establish worker feasibility.

### REVE

**Citation/status.** Yassine El Ouahidi, Jonathan Lys, Philipp Thölke, Nicolas Farrugia, Bastien Pasdeloup, Vincent Gripon, Karim Jerbi, and Giulia Lioi. *REVE: A Foundation Model for EEG—Adapting to Any Setup with Large-Scale Pretraining on 25,000 Subjects*. NeurIPS 2025; [arXiv:2510.21585](https://arxiv.org/abs/2510.21585), submitted 24 October 2025; verified [conference paper, including appendices](https://papers.neurips.cc/paper_files/paper/2025/file/20a917f77773ac0fa8bea2bdd6606b66-Paper-Conference.pdf).

**Authors demonstrated — paper evidence capsule.** Raw-EEG masked reconstruction trains a transformer with `(x,y,z,patch-time)` Fourier/learned positional features, coordinate noise, and spatial/temporal block masking. Ten downstream datasets cover MI, speech imagery, arithmetic/stress, emotion, sleep, abnormalities, and events. Relevant populations include PhysioNet-MI 109, BCIC-IV-2a nine, arithmetic 36, and speech fifteen participants. PhysioNet/arithmetic split by participant; speech splits trials within participants. Evaluation includes supervised fine-tuning and frozen-encoder probes, not label-free deployment. Table 19's learned-position variant nearly matches the coordinate method on two tasks; removing position noise reduces their reported average. Sparse-channel results are task dependent: MI degrades more gradually than speech. Bipolar TUEV uses electrode-pair midpoint coordinates. Few-shot evaluation requires labeled target examples; its cross-dataset variant additionally uses labeled MI corpora. Pretraining normalizes using recording-session statistics and excludes downstream datasets; BCIC preprocessing is described as Euclidean alignment. These are not chronological target-statistic guarantees. ([Paper §§2–3, Appendix C–E](https://papers.neurips.cc/paper_files/paper/2025/file/20a917f77773ac0fa8bea2bdd6606b66-Paper-Conference.pdf))

**Release audit.** The [official project](https://brain-bzh.github.io/reve/) reports approximately 60,000 hours from 92 datasets and 25,000 people, releases weights, and specifies 200-Hz input. Its March 2026 code/data release does not imply that every upstream corpus is unrestricted. Repository HEAD inspected: [`06a7059a07c3dabd80aee60c3dbc1eca4bdbe1c7`](https://github.com/elouayas/reve_eeg/tree/06a7059a07c3dabd80aee60c3dbc1eca4bdbe1c7), dated 20 March 2026 UTC.

The pinned [encoder](https://github.com/elouayas/reve_eeg/blob/06a7059a07c3dabd80aee60c3dbc1eca4bdbe1c7/src/models/encoder.py) confirms shared per-channel patch embedding, training-only coordinate noise, and patch-index time. Its [position utility](https://github.com/elouayas/reve_eeg/blob/06a7059a07c3dabd80aee60c3dbc1eca4bdbe1c7/src/downstream_tasks/position_utils.py) resolves electrode names or position files and averages bipolar endpoints. The released [BCIC preprocessor](https://github.com/elouayas/reve_eeg/blob/06a7059a07c3dabd80aee60c3dbc1eca4bdbe1c7/preprocessing/preprocessing_bciciv2a.py) splits subjects 1–5/6–7/8–9, common-average references, filters at 0.3–50 Hz, and resamples four seconds to 800 samples. It contains no Euclidean alignment, contrary to the paper's 0.5–99.5-Hz-plus-alignment description. The inspected release therefore does not fully resolve the reported protocol.

**Our interpretation.** Coordinates retain *where* a measured voltage belongs; temporal patch indices retain ordering inside the supplied window. Accepting a new layout does not make arbitrary electrode exchange harmless: swapping voltages without matching coordinates changes the scientific input. Coordinate jitter changes metadata while leaving voltages fixed; real movement also changes volume-conducted mixtures, contact, and artifacts. Their equivalence is untested. A bipolar difference is not a monopolar voltage measured at its midpoint. Successful classification under that convention is empirical compatibility, not an exact forward model.

Noncausal attention within the already-delivered four-second window is compatible with the competition contract. Whole-future-session normalization is not. Upsampling 120-Hz competition data to a pretrained model's rate cannot restore missing bandwidth. The learned-position ablation also prevents crediting geometry alone for the large model's results: corpus, objective, architecture, and adaptation differ together.

**Untested PROTEUS component and falsifier.** Borrow only coordinate-defined neighborhood masking: mask a small contiguous scalp neighborhood and time interval during otherwise unchanged same-corpus training. Compare equal masking budgets for geometric versus random channel groups and no masking. Keep channel identity at inference. Falsify the geometry rationale if random groups perform equally or better across held-out participants, or masking suppresses one command despite a pooled improvement. This tests a small spatial prior, not a reproduction of REVE.

### Channel Adaptation for EEG Foundation Models

**Citation/status.** Kuntal Kokate, Bruno Aristimunha, Dung Truong, and Arnaud Delorme. *Channel Adaptation for EEG Foundation Models: A Systematic Benchmark Across Architectures, Tasks, and Training Regimes*. [arXiv:2604.23091v1](https://arxiv.org/abs/2604.23091), 25 April 2026. Verified six-page [full PDF](https://arxiv.org/pdf/2604.23091v1) and [HTML](https://arxiv.org/html/2604.23091v1); no peer-reviewed venue verified.

**Authors demonstrated — paper evidence capsule.** The benchmark compares learned channel projection, coordinate-based spherical-spline interpolation, 25 spherical-harmonic coefficients, and SSI followed by per-subject geometric-mean covariance whitening. Five externally pretrained backbones—BENDR, Neuro-GPT, EEGPT, LUNA, CBraMod—are tested with frozen probes and supervised full fine-tuning over 10–15 seeds. BCIC2A has nine participants split 1–3/4–6/7–9; PhysioNet has 109 split 70/19/20; FACED has 123 split 80/20/23; MDD has 64 with predefined subject splits; TUEV uses its official recording split. Tasks cover MI, emotion, depression, and events. Rigid inputs require adaptation; flexible backbones can lose performance with external adaptation during fine-tuning. Reported CBraMod/TUEV whitening changes from 39.4% probe to 16.7% fine-tuning. Source harmonics perform poorly on MI despite useful depression results. Whitening's target-data chronology is unspecified; supervised heads/projections require training labels. Reported seed-level significance does not establish participant-level uncertainty. ([Methods–limitations](https://arxiv.org/html/2604.23091v1))

**Audit gaps and our interpretation.** No benchmark repository, complete seed tables, supplement, or covariance-fitting implementation was linked in the inspected paper/arXiv page or located by targeted search. Consequently I cannot verify whether target whitening uses all a held-out person's windows, how validation is constructed for TUEV, or whether the declared metric is implemented consistently. The paper calls its outcome macro accuracy/equivalent balanced accuracy, yet explains a constant-class FACED result of 12.5% by class imbalance. **If all nine classes occur**, a constant classifier's balanced accuracy is exactly 1/9, independent of class prevalence. That arithmetic makes precise numerical comparisons provisional, without proving every result wrong.

Interpolation preserves a smooth scalp-field approximation, not information absent from the original sensors. Learned projection preserves whatever labeled optimization finds useful; it supplies no anatomical guarantee. Low-order harmonics emphasize coarse spatial patterns, but are not identified cortical sources. The [OmnEEG dependency README](https://github.com/brain2vec/OmnEEG) separately marks anatomical source reconstruction as unfinished. Whitening changes covariance relative to an estimated reference; an invertible map can retain signal information mathematically while still making a frozen decoder ineffective. Conflicting gradients and focal-versus-global explanations in the discussion remain hypotheses, not mechanistic interventions. Neither deep spatial filters nor attention weights identify neural generators.

**Untested PROTEUS component and falsifier.** Test shrinkage covariance normalization on the existing 41 channels, without forcing an unnecessary 19-channel montage or importing weights. Fit source references on training people only. Compare frozen inference with a current/past-window session reference initialized/reset identically; include the current window only if consistently specified. No labels, IDs, future windows, or previous-session statistics enter prediction. Replay chronology and score equal cells. Falsify usefulness if gains disappear under causal replay, fail across held-out participants, or trade improved average performance for repeated command collapse. Test encoder training regime separately; the paper does not authorize assuming normalization helps EEGNet.

## Agent C — masking and representation objectives

Research date: 28 October 2026, Asia/Kolkata. Research only; no experiments, submission, infrastructure, or decoder changes.

**Decision — our interpretation.** Borrow the controlled comparison and shortcut diagnostics. Do not adopt a published mask as optimal for PROTEUS, or import external checkpoints under the user's fixed single-corpus constraint. SSL must earn its place against supervised spectral/covariance baselines and a matched scratch encoder. Predicting missing EEG is useful only if the representation retains distinctions between the three commands across people or sessions.

**Verified lead and bounded primary evidence.** Pierre Guetschel, Bruno Aristimunha, Yassine El Ouahidi, Arnaud Delorme, Thomas Moreau, Michael Tangermann: *What masking geometry works best for EEG foundation models?* arXiv:2609.33487v1, submitted 27 September 2026; [preprint, not established peer-reviewed publication](https://arxiv.org/abs/2609.33487). **Authors demonstrated:** 58 MAE/JEPA models; shared 4.4-TB corpus, 30-second/32-channel windows, ten epochs; twelve downstream EEG datasets. Frozen ridge probes use 5,000-dimensional random projections; five seeds vary projection, not SSL initialization. Best nominal geometry: two patches/9 cm; eleven MAE/nine JEPA configurations are not distinguished under dataset/probe-seed bootstrap. All-channel temporal masking yields JEPA position-dominated bias inflation and poor low-band decoding. PhysioNet-MI overlaps pretraining; eleven datasets are described as unseen. Main text says VICReg/C-JEPA do not rescue collapse; Appendix E.5 explicitly says this was not tested. Realized masking differs from 55%: 53.4% at the recommended geometry, 66.6% at all-channels/L16. Aggregate unique-participant count is unspecified. [Methods, results, limitations, Appendices A/C/E](https://arxiv.org/html/2609.33487v1).

**What the implementation actually asks the encoder to preserve.** The inspected [MAE implementation](https://raw.githubusercontent.com/PierreGtch/eeg-fm-masking/main/eeg_fm_masking/pl_mae.py) targets detached raw patches; [JEPA](https://raw.githubusercontent.com/PierreGtch/eeg-fm-masking/main/eeg_fm_masking/pl_ssl.py) targets detached contextual EMA-encoder outputs. Both exclude padding from masked MSE. JEPA's monitored variance pools batch, channel, and time positions. The [tokenizer/mask/loss code](https://raw.githubusercontent.com/PierreGtch/eeg-fm-masking/main/eeg_fm_masking/modules.py) uses overlapping channel-wise patches and radius-based spatial blocks.

**Our interpretation:** reconstruction rewards predictable voltage structure, including artifacts and redundant scalp mixtures; it does not select task-relevant structure automatically. Latent prediction lets the teacher discard details, but teacher agreement does not establish that discarded details are nuisance. A representation can vary across electrode positions while barely varying across trials at a fixed position. Therefore, ordinary pooled variance can confuse identity diversity with information about the current EEG. Keep electrode identity as useful context, but demand input dependence conditional on that identity. This is an argument for diagnostics, not removing all position information.

Autocorrelation and volume conduction offer different easy prediction routes. A scattered mask can leave nearby samples or neighboring electrodes sufficient to interpolate targets; an aggressive mask can remove evidence needed for a meaningful target. Neither extreme establishes invariance to reference, gain, contact changes, or a different person's physiology. For our task, retaining band-specific power and spatial relations is a plausible requirement; preserving those quantities is still insufficient proof of preserving class information. Evaluate both.

**Transfer and controls audit — our interpretation.** Equal corpus, schedule, and architecture strengthen the within-study geometry comparison. Realized mask fractions weaken exact matching; equal observed tokens also do not imply equal teacher-inclusive FLOPs or decoder work. A headline compute saving against a different hardware/model/data recipe cannot isolate a masking benefit. Multiple near-ties argue against treating one grid cell as uniquely optimal. Probe-seed uncertainty does not measure repeated pretraining or new-participant uncertainty. Bootstrap ranks over a selected benchmark do not establish equivalence, and a winner selected on that benchmark needs an independent confirmation set.

The [current OpenEEGBench configurations](https://raw.githubusercontent.com/braindecode/OpenEEGBench/main/open_eeg_bench/default_configs/datasets.py) show heterogeneous transfer: arithmetic has 36 subjects, split 28/4/4; BCIC-IV-2a has nine, split 3/3/3; PhysioNet-MI has 109, split 70/19/20. BCIC2020-3 separates runs, and SEED-V separates sessions. Other tasks include clinical diagnosis/events, sleep, emotion, and vigilance; this is not twelve replicas of our command-transfer task. Downstream participant separation cannot undo upstream SSL exposure. I could not verify recording/participant exclusion for the overlapping corpus. A stronger comparator scoring higher on that dataset does not prove overlap harmless. Repeated benchmark use can also select methods indirectly without gradient leakage.

## Agent D — drift and stable dynamics

Investigated 28 October 2026, Asia/Kolkata.

**Finding.** NoMAD supports recovering a fixed motor decoder's usefulness after recording changes within an individual. It motivates a constrained adapter experiment; it does not establish invariant biological computations, cross-person EEG transfer, or a PROTEUS improvement.

**Verified citation and status.** Brianna M. Karpowicz, Yahia H. Ali, Lahiru N. Wimalasena, Andrew R. Sedler, Mohammad Reza Keshtkaran, Kevin Bodkin, Xuan Ma, Daniel B. Rubin, Ziv M. Williams, Sydney S. Cash, Leigh R. Hochberg, Lee E. Miller, and Chethan Pandarinath. “Stabilizing brain-computer interfaces through alignment of latent dynamics.” *Nature Communications* **16**, 4662, published 19 May 2025; accepted 24 April 2025. DOI: [10.1038/s41467-025-59652-y](https://www.nature.com/articles/s41467-025-59652-y). This is a published, peer-reviewed article. The repository still cites its 2022 preprint; that stale README does not determine publication status.

**Demonstrated result.** Two macaques had 96-channel M1 recordings: eight-target wrist force, 20 sessions/95 days; eight-target reaching, 12 sessions/38 days. Median all-pairs transfer R² was 0.91/0.78, versus ADAN 0.65/0.29 and Aligned FA 0.59/0.17. One human, T11, contributed 192-channel intracortical cursor recordings from two sessions for retrospective within-session analysis. Day 0 requires behavior labels; monkey reference modeling also predicts force/derivative or position/velocity. Day K alignment uses neural data without behavior targets. Continuous sessions become 80/20 training/validation chops, with limited overlap. Monkey alignment and normalization use the target session before evaluation. Sliding-window inference uses current/past bins. Decoding evaluates selected successful movements, with behavioral timing and baseline correction. Thus the headline supports within-individual recording transfer, not unseen-person or scalp-EEG transfer. [Full primary text](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC12089531/fullTextXML).

**What is fixed, and what learns.** Static inspection of the [released implementation, commit aa3c8faadf053d0b22160458854c076dcb13eb7e](https://github.com/snel-repo/nomad/tree/aa3c8faadf053d0b22160458854c076dcb13eb7e), resolves a naming trap. The recurrent dynamics/encoder/controller core stays fixed. The input mapping, alignment network, generator-state-to-factor mapping, and factor-to-rate mapping can learn. In the demo configuration, the trainable attribute named `generator` is the added feedforward aligner, not the recurrent LFADS generator. Its implementation has three dense layers, two ReLUs, and group normalization, whereas the Methods describe a two-layer alignment network. The behavioral Wiener/OLE decoder is separately fitted and then fixed for NoMAD alone. Alignment combines spike reconstruction with KL between full-covariance Gaussian approximations of pooled generator states; code adds covariance jitter. [Configuration](https://github.com/snel-repo/nomad/blob/aa3c8faadf053d0b22160458854c076dcb13eb7e/demo/configs/nomad.yaml), [model and loss](https://github.com/snel-repo/nomad/blob/aa3c8faadf053d0b22160458854c076dcb13eb7e/nomad/nomad/models.py).

Our interpretation: the intended preserved information is enough temporal state to recover the reference motor output. Changing channel identity, channel count, and firing-rate scale can be absorbed only when remaining observations still constrain that state. A fixed core cannot reconstruct behavior information destroyed by recording loss. Neural reconstruction also rewards activity unrelated to the task; neither Gaussian alignment nor a bottleneck guarantees selective removal of nuisance information. Its tolerances should be established behaviorally, not inferred from a well-aligned plot.

**Calibration and future information.** The monkey protocol is transductive session adaptation followed by causal inference. Causal output computation does not make the fitted normalization or alignment parameters available at the session's beginning. No convincing minimum target-data curve establishes performance after one or several four-second EEG windows. Labels used only to score/filter movements are different from labels entering alignment, but they still narrow what the reported metric represents. Likewise, all ordered session pairs reuse animals and sessions; they are not hundreds of independent participants or a purely earlier-to-later prospective study.

The human analysis supplies a different boundary: Supplementary Figure 10 fits alignment from preceding blocks, excluding the evaluation block. RTI additionally obtains behavioral targets from known successful cursor acquisitions. Figure 12 removes alignment/KL together and uses a reference LFADS model without behavioral readout; it is a bundled ablation. Figures 1, 3, and 14 examine reference supervision, inference direction, and normalization. [Supplement, Figures 1–16 and Tables 1–8](https://pmc.ncbi.nlm.nih.gov/articles/instance/12089531/bin/41467_2025_59652_MOESM1_ESM.pdf).

Our interpretation: those controls support the complete procedure in the tested setting. They do not isolate an exclusive contribution from temporal dynamics, KL, or supervision. The comparison with a fixed TNDM model also changes more than dynamics. A decoder intervention tests a computational dependency: changing this algorithm changes predictions. It does not establish that the corresponding latent dimensions are biological causes of movement, or that neurons implement the learned recurrent equations.

**Identifiability and mixtures.** Coordinate equivalence is insufficient evidence for neural invariance: several transformed latent systems can yield the same behavior and observations. Matching means/covariances cannot identify which task meaning occupies a coordinate. A rotation, class permutation, or loss of minority-class separation may preserve pooled moments. The fixed core supplies additional constraints, but a controller with inferred inputs can accommodate discrepancies; physiological invariance is not identified uniquely.

For PROTEUS, the target marginal is a mixture, p(z) = Σᵧ p(z|y)p(y). A shift in class occupancy changes its moments even if every class-conditional representation remains stable. Conversely, unchanged pooled moments can conceal damaged class information. Thus a low alignment loss cannot alone certify harmless drift. Class-conditioned alignment with true future labels would answer an unavailable-information problem; pseudo-label conditioning instead inherits classifier mistakes. These are mathematical failure modes and proposed diagnostics, not claims that the paper suffered those failures.

**Untested fixed-corpus hypothesis and falsifier.** Start with the existing frozen EEG classifier and one small, identity-initialized input or feature adapter; keep its classifier fixed. Compare no adaptation, causal statistical normalization, and the same adapter with weak reference-moment alignment. Use only existing training subjects to choose settings; use current/past unlabeled windows and reset state per session. Retain the competition's equal participant/session/interface-cell balanced accuracy. Examine earlier-to-later sessions separately from held-out people; two repeated-session people cannot establish broad longitudinal reliability. Borrowing architecture needs no external weights; using monkey-pretrained weights would violate the user's single-corpus preference.

A minimal component falsifier should compare true chronological streams against training-only, class-reweighted streams while keeping the adapter's inputs unlabeled. If alignment loss falls while balanced accuracy or a class recall falls, reject alignment loss as a safety signal. If an adapter gain vanishes against normalization alone, do not credit stable dynamics. Before reusing demo utilities, test prefix invariance: append future samples and require unchanged previous predictions. Static inspection found that `chop_and_infer` fills initial N−1 bins from the first complete window; startup outputs therefore need explicit scrutiny. This flags released-demo behavior, not proof that the article's complete analysis is invalid. [Demo utility](https://github.com/snel-repo/nomad/blob/aa3c8faadf053d0b22160458854c076dcb13eb7e/demo/utils.py).

## Agent E — Augmentation and generalization safeguards

Verified 28 October 2026, Asia/Kolkata. **Recommendation: test modest real-data augmentation first; treat synthetic generation as optional research.** The lead is real, but the public implementation leaves important protocol questions unresolved. No experiments, submissions, project-code changes, or cloud actions were performed.

**Citation and authors’ evidence.** Daniel Choi, Cordelia Yip, Andrew Choi, Junho Park. *Trust-gated synthetic EEG augmentation reduces performance drops when generalizing to new patients*. **npj Digital Medicine 9, 634 (2026)**, DOI [10.1038/s41746-026-02778-0](https://www.nature.com/articles/s41746-026-02778-0). Published 25 May; version of record 18 August 2026; published open-access article. PainMunich: resting EEG, 189 people (101 pain/88 controls), 3.75-second windows at 200 Hz. BCI IV-2a: nine people, binary left/right imagery, 22 EEG channels, 250 Hz, 0–4-second epochs padded to 1,024. Evaluation: participant-disjoint train/validation/test; five folds × five seeds; participant scarcity. At 25% motor-imagery scarcity, EEGNet AUROC is 0.679 with q=.99 versus 0.627 real-only; harm rates are 0.16 versus 0.44 ungated. Seeds, splits, candidate pools, preprocessing and ratio selector are paired across conditions. Ratio selection requires validation AUROC gain≥0.01. Pooled harm is nonmonotonic in q. These are authors’ results, not our replications. [Article](https://www.nature.com/articles/s41746-026-02778-0?error=cookies_not_supported)

**What information could survive?** Our interpretation: a conditional generator approximates the training distribution associated with labels. A covariance teacher rewards examples that preserve its discriminative second-order structure; it does not establish preserved temporal dynamics, physiological validity, or invariance to new participants. High confidence can amplify a teacher’s shortcuts and prefer easy prototypes, reducing useful diversity. Generated windows do not become independent participants or expand the observed support of human variation simply because there are more samples.

**Mechanism, checked in public code.** The teacher fits Ledoit–Wolf covariance → matrix logarithm → upper-triangle features → scaling/logistic regression using real training windows. Acceptance requires nominal-label agreement and a confidence quantile computed among agreeing synthetic candidates. Thus “trust” is agreement with a particular trained classifier, not verified label correctness or calibrated probability of physiological validity. The code does not implement a separate confidence-calibration stage. [Teacher implementation, lines 167–255](https://github.com/danielchoi0315/TGA-repo/blob/main/tga/runner.py#L167-L255)

There are two material release-to-paper discrepancies:

1. **Minimum acceptance changes the gate.** Below 200 agreeing examples, code returns empty. But when fewer than 200 survive the quantile, it retains the top 200 agreeing examples instead of disabling augmentation. Consequently, the actual accepted set can include candidates below the requested confidence threshold. This differs from the stated quantile-then-fail-closed safeguard. Do not silently reproduce this relaxation. [Exact branch, lines 238–251](https://github.com/danielchoi0315/TGA-repo/blob/main/tga/runner.py#L238-L251)
2. **Generator fitting boundary needs provenance.** The motor builder obtains an outer GroupKFold train/validation pool and directly fits on all its examples and labels. It has no inner validation split or scarcity argument. This appears inconsistent with a generator restricted to the scarce inner training participants. The pain replay separately creates inner validation and scarcity subsets before teacher fitting, demonstrating why “outer training” and “training available to the decoder” are different boundaries. These released paths do **not** prove that every published run used that protocol; matching run manifests are needed. [Motor split and fitting, lines 142–147 and 217–220](https://github.com/danielchoi0315/TGA-repo/blob/main/scripts/tga_train_motor_ddpm_unet_ema.py#L217-L220); [pain replay, lines 176–195](https://github.com/danielchoi0315/TGA-repo/blob/main/scripts/tga_replay_pain_subject_level.py#L176-L195)

**What the safeguards demonstrate—and leave open.** The supplementary evidence reports harm as ΔAUROC < −0.01, not patient injury; worst-decile motor-imagery ΔAUROC improves from −0.106 to −0.041. Matched-volume random gating sometimes beats trust gating. Accepted classes become skewed. Kept/rejected covariance-distance ratios remain near one. Thus improved safety cannot be assigned uniquely to confidence filtering. [Supplement, Tables S1–S2 and Figures S1–S4](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41746-026-02778-0/MediaObjects/41746_2026_2778_MOESM1_ESM.pdf)

Our audit interpretation: a large synthetic/real covariance mismatch flags an unsupported distribution; it neither proves that mismatch caused harm nor shows that the gate repaired it. Report class-wise acceptance, injected class proportions, covariance distances, spectral content and downstream class recalls together. A classifier can confidently endorse off-distribution examples. Balanced loss does not automatically correct an altered synthetic class mix.

Validation fail-closure limits exposure; it is not a guarantee on unseen people. Searching ratios, stopping epochs and comparing quantiles repeatedly on the same validation participants can overfit selection. Preserve a nested participant split, freeze the complete policy, then evaluate outer participants once. The random-gating script copies selected synthetic counts/ratios and uses a different training-seed formula; it is not a fully paired re-run of the entire random-gate selection procedure. Compare both equal-volume curation and complete policy effects. [Control implementation, lines 159–215](https://github.com/danielchoi0315/TGA-repo/blob/main/scripts/tga_random_gating_negative_control.py#L159-L215)

Twenty-five seed/fold runs are not 25 independent cohorts: test people recur across seeds and training sets overlap across folds. Cluster uncertainty by participant, retaining sessions within participant, and show individual deltas and the worst cases. A lower fraction crossing one threshold can coexist with substantial remaining failures. Avoid selecting a favorable scarcity, architecture or quantile from the outer-test results.

**Competition transfer boundary.** The released normalization computes each held-out person’s channel statistics over all their windows and time samples. That requires person grouping and future windows. Replace it with training-only statistics, current-window processing, or causal session updates; never carry adaptation across reset. This is a deployment incompatibility, not evidence of label leakage. [Normalization, lines 147–161](https://github.com/danielchoi0315/TGA-repo/blob/main/tga/runner.py#L147-L161)

PROTEUS instead supplies one chronological 41×480 EEG window at 120 Hz, covering seconds 1–5; its labels are imagery/subtraction/word generation. No participant IDs, target labels or extra labeled calibration arrive. Score equal participant × session × interface balanced accuracy, not binary AUROC. Consequently, this paper supports an augmentation-governance hypothesis across two EEG settings; it demonstrates neither these three commands nor causal later-session transfer. Training-fold real labels suffice for a proposed local teacher/generator; external pretrained weights are unnecessary and outside the user’s single-corpus experiment. [Official scientific FAQ](https://raw.githubusercontent.com/neural-interfaces26/2026-competition/main/codabench/pages/scientific_faq_bci.md)

Choose severity only inside training/validation participants. Keep architecture, initialization seeds, optimizer-update budget and checkpoint policy paired; inspect subtraction recall and prediction proportions as well as equal-cell BA.

Only if that warrants further work, fit a generator and three-class teacher strictly inside each inner training split. Compare real-only, light perturbation, ungated synthetic, teacher-gated synthetic and class/volume-matched random synthetic. Prespecify one gate/ratio search and a BA improvement margin; return to real-only if validation benefit is insufficient. Never use outer labels or full future-session statistics to select samples or policy. **Falsifier:** gating fails if it cannot outperform matched-volume random selection across held-out participants, worsens worst-participant/class recall, or depends on future-window normalization. There is currently no PROTEUS augmentation gain to report; the recorded EEGNet seeds are one fixed split, not participant folds. ## Coordinator synthesis: evidence map

These mechanisms address different failures; they are not mutually interchangeable remedies for one diagnosed bottleneck.

| Mechanism | Information it tries to retain | Variation it may tolerate | What limits the inference |
|---|---|---|---|
| Sinc/constrained temporal filters | Selected oscillatory components and their temporal evolution | Some irrelevant out-of-band activity; fewer free filter coefficients | Relevant bands vary by task/person; filtering can discard useful information. Binary-MI findings do not settle three-command transfer. |
| Coordinate-aware input/masking | Where a signal belongs on the scalp | Missing channels, coordinate uncertainty or layouts under tested conditions | Fixed geometry is not a calibrated physical model of electrode displacement. External pretraining and geometry effects are confounded. |
| Covariance normalization | Spatial fluctuation structure relative to a reference | Some gain/mixing differences | A marginal reference also changes with task mix; whitening can remove useful distinctions or destabilize an encoder. |
| MAE/latent prediction | Predictable signal or teacher-defined features | Only variations that the learned representation actually ignores | Predictable artifacts, interpolation shortcuts, identity-dominated features, collapse and pretraining overlap. |
| Frozen dynamics + small alignment | Reusable state transitions/behavioral mapping | Changes in the observation-to-state mapping | Different behavior, lost information, whole-target fitting, and ambiguity of unlabeled alignment. |
| Gated augmentation | Task-consistent variation according to a teacher/validation rule | Selected perturbations represented in training | Teacher bias, class-skewed acceptance, synthetic distribution errors, selection overfitting and mismatched data budgets. |

**Agreement:** keep task-discriminative structure, limit unsupported degrees of freedom, separate source learning from target adaptation, and judge utility on held-out people/sessions. **Disagreement or non-comparability:** papers optimize different objectives and metrics on different populations; some fit target distributions offline, some require target labels, and others only evaluate frozen representations. Their numerical gains cannot be added or transferred to our score.

There is no supported conclusion that covariance universally beats temporal networks, that JEPA universally beats reconstruction, or that geometry always improves decoding. A method can look stable because it removed both nuisance and task information. Conversely, a session-specific feature can be genuinely task-relevant.

For window features Z, even unchanged class-conditional distributions can have changing marginal covariance:

\[
\mathrm{Cov}(Z)=\sum_y\pi_y\mathrm{Cov}(Z\mid y)
+\sum_y\pi_y(\mu_y-\mu)(\mu_y-\mu)^\top.
\]

Here \(\pi_y\) is the class proportion. This identity explains why matching an unlabeled distribution is not automatically removing recording drift: it can instead respond to which tasks appeared recently. It also explains why a more confident or less novel representation need not be more accurate.

## Competition fit and exclusions

| Category | Candidate | Boundary |
|---|---|---|
| Compatible as a source-trained component | Band power, shrinkage covariance, constrained filters, static coordinates, small within-window temporal summaries | Fit all learned choices on training participants and use the supplied bandwidth/montage. No benefit is yet measured here. |

Specific leakage controls: split by participant before feature fitting, SSL or augmentation; keep all crops/overlapping windows of a trial together; do not use future target windows for normalization; select using inner validation rather than outer test or leaderboard; and report the official cell metric rather than pooled accuracy. A fixed current-window transform is not automatically leakage. Offline transductive protocols can be legitimate for their stated question but do not establish compatibility with ours.

### Experiment 1 — identify what representation helps

- **Hypothesis:** explicit oscillatory power or spatial second-order structure is easier to estimate with our data than the current learned representation.
- **Minimal change:** compare the unchanged EEGNet and channel-mean control with a small band-power + regularized classifier and shrinkage-covariance + regularized classifier. These are diagnostic controls, not new 2026 techniques.
- **Comparison/ablation:** common windows, participant folds, label budget and selection policy; fit scaling, spatial filters, covariance reference and classifier within each fold. Predeclare a small representation/tuning menu rather than exhaustively searching frequency bands.
- **Metric:** shared cell BA and class recalls; inspect paired participant differences.
- **Against the hypothesis:** no consistent advantage over matched EEGNet across held-out people, or benefit concentrated in one person/interface. That would not prove the features contain no task information; it would reject this practical advantage under the tested recipe.

### Experiment 2 — isolate constrained frequency learning from BTTA-DG

- **Hypothesis:** restricting temporal filters to meaningful bandpasses reduces estimation error without removing command information.
- **Minimal change:** a Sinc-style front end in an otherwise matched small source-trained decoder, with valid cutoffs below the 120-Hz input's Nyquist limit. No imported checkpoints or GMM adaptation.
- **Comparison/ablation:** constrained versus unconstrained temporal filters; hold pooling, normalization, spatial stage and training schedule fixed as far as possible; record parameter counts. Compare with the strongest representation control from Experiment 1 using nested selection, not public-test choice.
- **Validation/metric:** the shared participant protocol; cell BA, class recall and seed variation.
- **Against the hypothesis:** equal/worse held-out performance, loss of subtraction/word-generation recall, or a gain explained by a changed normalization/training budget rather than filter constraints. Attractive learned passbands alone do not support the hypothesis.

### Experiment 3 — test whether causal normalization removes useful mismatch

- **Hypothesis:** a meaningful part of transfer failure is a nuisance change that current/past-window statistics can reduce.
- **Minimal change:** freeze a selected source decoder and compare its existing preprocessing against a regularized per-session prefix reference initialized from training data. Match any corresponding source preprocessing during training. Specify whether the current window is included; both the information boundary and ordering must be reproducible.
- **Comparison/ablation:** source-only fixed reference versus causal reference; no parameter updates, IDs or target labels; identical reset/cold-start policy. Test robustness to naturally occurring class mixtures; do not assume balanced prefixes.
- **Validation/metric:** chronological session replay; cell BA plus first-window/startup and class-specific losses. Group the exploratory later-session results by actual participant.
- **Against the hypothesis:** causal replay loses the apparent benefit, startup errors offset later gains, or normalization repeatedly collapses a command. This tests a statistical remedy, not the biological cause of drift.

### Experiment 4 — test one inexpensive robustness prior

- **Hypothesis:** modest label-preserving perturbations improve transfer without needing synthetic subjects or a new backbone.
- **Minimal change:** one gain/noise/dropout or spatial-temporal masking family on the selected small decoder; compare against real-only training. Magnitudes and budgets are new choices for inner validation, not imported paper optima.
- **Comparison/ablation:** for geometry, compare contiguous scalp neighborhoods with equal-budget random groups. If adding a teacher gate, compare no gate, teacher gate and matched-count random acceptance; include the teacher itself as a decoding baseline and a real-only fallback. Do not introduce a diffusion generator in this first comparison.
- **Validation/metric:** the same folds, label/tuning budgets and cell BA; show the distribution of paired participant changes and class-skewed acceptance.
- **Against the hypothesis:** matched random selection explains the gain, accepted examples increase class bias, or average improvement hides repeated participant/command harm. A subject-scarcity study is not evidence that more synthetic windows replace missing people.

**Deferred:** a full same-corpus SSL comparison, NoMAD-style dynamics alignment, and GMM output adaptation. If the earlier tests justify them, use compact models and separate each objective/adapter from the representation. For SSL, compare matched scratch/supervised compute, split before pretraining, and use only training participants' resting recordings if that addition is declared. For adaptation, keep an untouched starting model and compare the same held-out data before/after updates; better transfer and less forgetting are distinct outcomes. ## Open questions and evidence needed

1. **Which factor actually limits our baseline?** Only matched representation/normalization/training comparisons can distinguish plausible bottlenecks; current scores do not diagnose them.
2. **Can a three-command target-memory method start safely?** Need empty/insufficient-class behavior, chronological code, bounded runtime, no target-label selection and a clean reference against the frozen decoder.
3. **Which published outputs correspond to which released preprocessing and selection path?** Author versioned experiment configurations/checkpoints or clarification would resolve the BTTA-DG, REVE and augmentation release gaps. Static differences do not establish misconduct.
4. **Are masked features task-sensitive after controlling for identity?** Need held-out probes and content/position diagnostics; reconstruction or pooled variance is insufficient. The paper's pretraining overlap also needs recording/participant mapping.
5. **Does alignment handle recording drift or class composition?** Need controlled within-development comparisons with fixed label budgets and natural chronological task mixtures. Unlabeled marginal statistics cannot universally identify harmful conditional drift.
6. **What is the enforceable submission/runtime limit?** Resolve the Terms/site discrepancy from the active platform or organizer before execution/submission planning. This review does not require consuming an upload.
