# Agent A: single-trial adaptation and frequency information

Research date: 28 October 2026, Asia/Kolkata. Research only; no models, experiments, submissions, or cloud resources were run.

**Judgment.** BTTA-DG offers portable architectural and prediction-summary ideas, but its released reproduction does not establish an eligible chronological adaptation gain. Separate the published results from demonstrable defects in the public implementation: those defects do not prove that every published experiment used the defective paths. No PROTEUS improvement is demonstrated.

## Verified paper and reported evidence

Huan Luo, Na Lu, Xiaopeng Wang, and Xu Niu. **“Bayesian Test-Time Adaptation via Dirichlet feature projection and GMM-Driven Inference for Motor Imagery EEG Decoding.”** Published conference paper, **ICLR 2026**, verified through the [official proceedings entry](https://proceedings.iclr.cc/paper_files/paper/2026/hash/36eeec256f89eba9ed60cbca73ea92ed-Abstract-Conference.html) and [full paper including appendices](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf). The [author repository](https://github.com/luo-huan-123/BTTA-DG) identifies itself as the official implementation.

**Authors’ demonstrations:** binary scalp-EEG imagery, primarily first-session LOSO; BNCI2014001 also session 1→2 within participant. Dataset specifications are:

| Dataset | Participants | Channels; Hz; trial duration | Imagery comparison |
|---|---:|---|---|
| BNCI2014001 | 9 | 22; 250; 4 s | Left/right hand |
| BNCI2014002 | 14 | 15; 512; 5 s | Right hand/feet |
| BNCI2015001 | 12 | 13; 512; 5 s | Right hand/feet |

The method combines source-supervised SincAdaptNet, per-trial Dirichlet prediction summaries, and historical classwise GMM calibration. Ten-run mean accuracies: BNCI2014001/002/5001 LOSO **78.70/80.29/77.92%**; BNCI2014001 cross-session **86.50%**. EA-equipped source comparators: **77.03/78.05/75.48/82.33%**, respectively. Appendix E claims source-held-out hyperparameter selection, batch one, memory 1000, eight mixture components; Table 7 reports **15.7 ms/trial** on the stated TITAN V/Xeon setup. SHU’s improvement lacks statistical significance. These are reported accuracies, not competition cell-balanced accuracy. [Paper, Tables 2–8; Appendices E–I](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf).

## What the representation actually preserves

**Our mathematical interpretation:** the Dirichlet estimator uses time-averaged log probabilities. Permuting the columns of an already-computed prediction trajectory leaves its estimate unchanged. Thus it can retain class preference and within-window predictive dispersion, while discarding temporal order, transition timing, and distinctions between trajectories with identical sufficient statistics. It cannot preserve task information already removed by the encoder. This is a narrower claim than preserving arbitrary temporal dynamics. Adjacent filtered EEG samples also need not behave like independent draws; fitted concentration is therefore a descriptive feature, not automatically calibrated biological uncertainty. This reasoning follows [Equations 2–4](https://proceedings.iclr.cc/paper_files/paper/2026/file/36eeec256f89eba9ed60cbca73ea92ed-Paper-Conference.pdf).

**Our interpretation:** classwise density correction can tolerate a change in where otherwise useful predictive patterns fall. It cannot identify a reversed class mapping without an anchor. Confidence-based admission remains pseudo-label-dependent despite frozen network weights. Multiplying a density and a network prediction derived from the same EEG is a calibration heuristic; their dependence prevents treating the product as independent new evidence. It does not independently estimate a new target class prior. Wrong confident predictions can contaminate memory without changing a single weight.

## Released-code audit and information requirements

Audit pinned to **5932d026bbd8a7de106d31a6d264f4f4924537e4**, the public `master` commit retrieved on the research date. Line numbers below are actual downloaded raw-file lines, not browser-extraction indices.

- **Adaptation path:** [`BTTA_DG.py`](https://github.com/luo-huan-123/BTTA-DG/blob/5932d026bbd8a7de106d31a6d264f4f4924537e4/BTTA_DG.py#L144) initializes empty buffers at 144. The sole insertion is `add_sample` at 161–169; tree-wide search finds no caller. The online loop calls `clusterer.update(alpha, pred, prob_map)` at 284, which only fits existing buffers; fallback at 210–216 returns original probabilities. Therefore this released path cannot demonstrate GMM adaptation. Its `EA(test_x)` at 351 estimates alignment from the entire target array before batch-one delivery: future-target access. Target labels in this inference loop only score predictions. Checkpoints are ensembled; the buffer is recreated per adaptation invocation. The prior averages log probabilities, unlike arithmetic probability averaging; estimation lacks clipping and variance-zero protection. BNCI2014001 uses six mixture components versus Appendix E’s eight. [Raw source](https://raw.githubusercontent.com/luo-huan-123/BTTA-DG/5932d026bbd8a7de106d31a6d264f4f4924537e4/BTTA_DG.py).
- **Checkpoint selection:** [`pretrain_SincAdaptNet.py`](https://github.com/luo-huan-123/BTTA-DG/blob/5932d026bbd8a7de106d31a6d264f4f4924537e4/pretrain_SincAdaptNet.py#L56) constructs the evaluation loader from target data/labels at 56–58, evaluates them each epoch at 87–94, selects with `if acc > best_acc:` at 95–97, and saves at 101. This requires unavailable target-label information for the released checkpoint recipe. Its ten “folds” repeat the same split. Default execution also lacks `args.method` required by the loader, and cropped outputs at 73–76 are paired with full-length repeated labels at 77. These are static reproducibility findings, not executed failures. [Raw training file](https://raw.githubusercontent.com/luo-huan-123/BTTA-DG/5932d026bbd8a7de106d31a6d264f4f4924537e4/pretrain_SincAdaptNet.py), [loader](https://raw.githubusercontent.com/luo-huan-123/BTTA-DG/5932d026bbd8a7de106d31a6d264f4f4924537e4/utils/dataloader.py).
- **Frequency extraction:** [`SincAdaptNet.py`](https://raw.githubusercontent.com/luo-huan-123/BTTA-DG/5932d026bbd8a7de106d31a6d264f4f4924537e4/SincAdaptNet.py) learns spatial mixing and windowed bandpasses, then uses layer normalization and per-time classification. Its upper cutoff cap is 100 Hz, not sampling-rate Nyquist. Porting to 120 Hz therefore requires a valid sub-60-Hz parameterization. The [download script](https://raw.githubusercontent.com/luo-huan-123/BTTA-DG/5932d026bbd8a7de106d31a6d264f4f4924537e4/download_data.py) leaves MOABB filter settings at defaults; pinned MOABB 1.1.1 uses [8–32 Hz](https://raw.githubusercontent.com/NeuroTechX/moabb/v1.1.1/moabb/paradigms/motor_imagery.py), inconsistent with the paper’s 1–48-Hz preprocessing statement. Filter passband plots alone cannot show that gamma task information survived input preprocessing.

“Pretraining” here means supervised training on source participants, not demonstrated foundation-model transfer. The portable component is an architecture/trainable summary; external pretrained weights are unnecessary. Released code does not provide evidence for cross-task, cross-device, montage-independent, or three-command transfer. Spatial weights still assume corresponding channels.

## Minimal project hypothesis and falsifier

**Untested proposal:** first compare a source-trained Sinc front end against the existing EEGNet using the same public training corpus, split, checkpoint-selection policy, and parameter budget. Separately compare frozen temporal-probability means with clipped mean-log/concentration summaries using a small source-trained classifier. This isolates spectral bias from adaptation and avoids cold-start memory ambiguity. Falsify the proposal if source-only summaries fail to improve validation cell-balanced accuracy consistently across the existing seeds, or if gain disappears under the official participant-session replay.

Only then consider a causal memory calibrator. Algorithm 1 takes memory banks as input without resolving cold start. An eligible target-memory implementation must reset each session, define insufficient-class fallback, and measure startup versus later-window performance and latency. For an initially empty target-only memory, our proposed control predicts before storing the current pseudo-label; that ordering is a design choice, not a competition rule. The [current official FAQ](https://raw.githubusercontent.com/neural-interfaces26/2026-competition/main/codabench/pages/scientific_faq_bci.md) also permits label-free adaptation on the current window. Warm-start target labels, session identifiers, future windows, and cross-session state are unavailable. Balanced target class proportions must not be assumed; a uniform prior could be tested as an explicit modeling choice. The short streams and three heterogeneous commands make missing-class memory and confident mistakes concrete falsifiers. Published hardware timing cannot establish worker feasibility.
